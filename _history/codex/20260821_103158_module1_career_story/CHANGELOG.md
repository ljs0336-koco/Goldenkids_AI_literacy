# 모듈 1 꿈·진로 탐색 이야기 전환

## 변경 이유

- `코딩 메이커 9점`처럼 출처를 알 수 없는 추천 점수가 학생에게 직관적이지 않았다.
- 체험 활동 추천은 학생이 자신의 삶과 연결해 생각하기 어려웠다.
- 압축된 안내 문장이 주어와 대상이 불분명해 어색하게 읽혔다.

## 새 이야기

1. AI는 초등학교 6학년 하늘이의 성적표와 코딩 과제 기록만 받는다.
2. 이 자료만 본 AI는 소프트웨어 개발자를 먼저 떠올린다.
3. 학생은 AI에게 그 이유와 빠진 정보를 질문한다.
4. 과학 설명 경험, 환경 프로젝트, 협업 선호, 하늘이가 직접 말한 바람을 한 장씩 확인한다.
5. 꿈 후보가 환경 소프트웨어 개발자, 환경공학자, 과학 커뮤니케이터로 넓어진다.
6. 학생은 직업 하나를 정답으로 고르지 않고 하늘이의 꿈을 더 알아볼 다음 행동을 선택한다.

## 화면 원칙

- 실제 성적표 점수는 자료로 보여 주되 AI가 만든 진로 적합도·추천 점수는 표시하지 않는다.
- `기록`, `단서`, `판단` 같은 추상어 대신 성적표, 과제, 경험, 관심, 하늘이가 직접 한 말처럼 구체적으로 쓴다.
- 학생이 읽는 문장은 행동의 주어와 대상을 분명하게 쓴다.
- 금쪽이 스피커 대화는 첫 화면의 작은 선택형 제안으로만 유지한다.
- 완료 화면의 큰 오프라인 연계 카드는 제거했다.
