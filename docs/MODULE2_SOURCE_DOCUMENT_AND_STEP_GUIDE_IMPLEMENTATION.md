# 모듈 2 자료 문서화·단계 안내 개선

작성일: 2026-08-24
범위: 모듈 2 전체 상단 안내, 활동 A 자료 선택·비교 화면
상태: 구현·자동 검증·브라우저 검증 완료

## 해결한 문제

1. `학교숲 개장일: ... / 이용 시간: ...`이 단순 인용문처럼 보여 실제 자료를 확인하는 느낌이 약했다.
2. 상단 `지금 할 일`과 과거 배포본의 하단 `지금 해볼 일`은 이름이 비슷하고, 현재 단계가 무엇인지 드러내지 못했다.

## 구현 내용

### 자료를 실제 문서 문법으로 표시

공통 `VerificationSourceDocument`를 모듈 2 내부에 추가했다.

- 학교 공식 공지: 문서 제목, 발행 기관, 게시일, `항목–값` 표
- 학교소식지: 소식지 머리말과 기사 본문
- 학생 설문: 참여 학생, 주요 응답, 조사로 알 수 없는 한계
- 개인 게시물: 작성자 확인 상태, 게시글 본문, 원출처 부재 표시

새로운 기관명·문서 번호·URL·조사 결과는 만들지 않았다. 기존 데이터에 이미 있던 사실만 구조화해 표시한다. 원래 `excerpt`도 엔진과 이전 테스트 호환을 위해 유지한다.

### 상단 안내의 역할을 명확히 구분

기존:

```text
지금 할 일
자료 봉투를 한 장씩 열고 ...
```

개선:

```text
이번 단계
비교 자료 고르기
자료를 한 장씩 열고 비교에 쓸 자료를 두 개 이상 남기세요.
```

학교신문 활동과 미디어 활동의 12개 화면 모두에 구체적인 단계명을 부여했다. `?` 버튼은 행동 지시를 반복하지 않고 그 활동이 AI 리터러시와 연결되는 이유만 보여 준다.

### 중복 안내 상태

- 현재 로컬 코드에는 하단 `지금 해볼 일` 팝업이 없다.
- 첨부 화면에 보인 하단 팝업은 이전 배포 번들의 화면이다.
- 상단 안내는 한 개만 유지하며, 본문의 A/B 선택 결과는 카드 안에서 표시한다.

## 화면 안정성

- 기존 자료 봉투의 최소 높이를 유지해 닫힘·열림·선택 결과 사이의 큰 레이아웃 변화를 막았다.
- 모바일에서는 공지 표가 한 열로 바뀌어 항목명과 값을 위아래로 읽는다.
- 자료 비교 화면도 같은 문서 컴포넌트를 사용해 자료 선택 화면과 시각 언어가 달라지지 않는다.
