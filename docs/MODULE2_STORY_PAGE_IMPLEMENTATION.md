# 모듈 2 페이지형 학생 경험 구현 기록

> 구현 기준 커밋: `b9faf27` (`feat: rebuild module 1 as guided stories`)
> 작업 영역: `src/features/verification/**`, 본 기록 문서, 전체 계획서의 구현 현황
> 비작업 영역: 모듈 1·3·4, 공용 홈·라우팅·스타일, 배포 설정

## 1. 구현 목표

기존 모듈 2의 많은 정보와 선택지를 한 화면에 나열하는 구조를, 학생이 사건을 따라가며 한 번에 한 가지 행동을 하는 페이지형 경험으로 바꾸었다.

- 프로그램명보다 학생이 마주할 질문인 **`진짜일까? 써도 될까?`**를 앞세운다.
- 첫 활동은 학교신문 마감 사건, 두 번째 활동은 미디어 게시 요청 사건으로 시작한다.
- 정답을 맞히는 퀴즈보다 `근거 확인 → 판단 → 결과물 수정`의 흐름을 경험하게 한다.
- 금쪽이 스피커 대화는 필수가 아닌 한 장면의 선택형 확장 메모로만 둔다.
- 교사 도구와 발표 모드는 학생 핵심 화면에서 제거하고, 인쇄 기록은 완료 화면의 보조 기능으로 옮긴다.

## 2. 활동 A — 학교신문 마감 전 AI 초안 확인

학생은 학교신문을 발행하기 전 마지막 편집자가 된다.

1. `마감 15분 전` 상황과 AI가 받은 작성 요청을 확인한다.
2. AI 초안의 세 문장을 한 장씩 넘기며 먼저 검증할 문장을 고른다.
3. 그 문장과 관련 있는 자료 봉투 세 개를 한 장씩 열어 작성자·날짜·내용을 확인한다.
4. 비교에 남길 자료를 두 개 이상 직접 고른다.
5. 선택한 자료를 한 장씩 읽고 마지막 장에서 내용을 함께 비교한다.
6. 문장에 `자료로 확인됨 / 근거가 더 필요함 / 고쳐야 함` 판정을 내린다.
7. 판정 이유를 고른 뒤, AI 문장이 실제 기사 문장으로 어떻게 고쳐지는지 확인한다.
8. 세 문장을 모두 처리하면 AI 초안과 검증 후 기사를 전·후로 비교한다.

세 사례의 차이는 유지했다.

- 서로 다른 공식 기록으로 확인할 수 있는 개장일
- 과거 자료와 최신 자료가 달라 고쳐야 하는 이용 시간
- 작은 의견 조사로 35% 향상을 일반화해 근거가 부족한 집중력 주장

각 문장에는 관련 자료 세 개만 보여 준다. 모든 자료를 한꺼번에 격자로 펼치지 않으며, 저장 상태에도 해당 문장에 허용된 자료 ID만 남도록 정제한다.

## 3. 활동 B — 게시 전 미디어 사용 판단

학생은 콘텐츠가 공개되기 전 사용 여부를 결정하는 확인 담당자가 된다.

1. 첫 방문에는 `동아리 진행자의 합성 목소리` 사건 하나만 필수로 제시한다.
2. 화면에서 직접 관찰할 수 있는 사실과 화면만으로는 모르는 정보를 한 장씩 구분한다.
3. 시각·청각적 이상은 첫 단서일 뿐 합성 여부를 확정하지 못한다는 점을 확인한다.
4. 원래 출처, 제작자, 제작·수정 이력, 당사자 동의를 한 장씩 연다.
5. 게시 전에 필요한 조치를 한 장씩 검토하고 선택한다.
6. `현재 정보로 사용 가능 / 현재는 사용하지 않음`을 먼저 비교하고, 필요하면 `조건을 고치거나 더 확인한 뒤 사용`이라는 제3안을 연다.
7. 게시 요청 원본과 최종 결정, 사용 전에 고쳐야 할 조건을 함께 확인한다.

대표 사건 완료 후에는 다른 세 사건을 선택형 도전으로 열어 둔다. 따라서 학생은 필수 경로를 짧게 끝낼 수 있고, 필요하면 실제 사진의 잘못된 맥락, AI 포스터, 합성 음성 패러디까지 확장할 수 있다.

## 4. 공통 학생 안내

- 헤더 도움말에는 `이 활동에서 하는 일`, `AI 리터러시와의 연결`, `막혔을 때`를 짧게 넣었다.
- 각 큰 단계 시작에 `지금 할 일`과 펼쳐 보는 `왜 확인할까요?`를 제공한다.
- 내부 페이지에는 이전·다음 버튼, 현재 장/전체 장 표시, 비활성화 이유를 함께 둔다.
- 완료 화면의 기록 인쇄 기능은 활동을 끝낸 뒤에만 접근한다.
- 학생에게 `가짜를 찾아라`라고 요구하지 않고, 출처·맥락·동의·피해 가능성을 확인해 사용 결정을 내리도록 표현을 통일했다.

## 8. 선택 경험 후속 개선

커밋 `7e28b18` 이후 모듈 1과 같은 선택 문법을 적용했다.

- 자료 봉투: `비교에 남긴다 / 이번 비교에서는 뺀다`
- 보이는 단서: `확인할 단서로 남긴다 / 결정적 단서로 쓰지 않는다`
- 게시 전 행동: `필요하다 / 필요하지 않다`
- 문장 판정: `자료로 확인됨 / 고쳐야 함`, 근거가 부족한 경우는 제3안
- 미디어 결정: `현재 사용 가능 / 현재 사용하지 않음`, 조건부 사용은 제3안

선택지는 한 장씩 넘기지 않고 같은 화면에서 바로 비교한다. 선택 뒤에는 다음 버튼을 찾기 전에 결과와 이유가 즉시 나타난다. 읽고 확인해야 할 자료·제작 정보에는 기존 페이지 넘김을 유지했다.

후속 개선 검증 결과 모듈 1·2 범위 테스트 60개, 전체 앱 테스트 95개, 전체 린트와 배포 빌드를 모두 통과했다.
