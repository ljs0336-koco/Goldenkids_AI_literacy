# 변경 기록

## 목적

모듈 2에서 확인된 `원본 자료와 조작 UI가 구별되지 않는 문제`를 전 모듈의 핵심 산출물까지 확장해 해결한다. 모듈 2의 크라프트 스타일은 자료 메타포로 유지하되, 다른 모듈에는 주체와 상태를 알려 주는 간결한 라벨만 적용한다.

## 변경 사항

- 공통 `ArtifactStatusLabel` 컴포넌트와 네 가지 상태 톤 추가
- 모듈 1의 입력 기록, AI 추천, AI 팀 추천에 상태 라벨 추가
- 모듈 2 기사 초안 문구 정리 및 모바일 줄바꿈 수정
- 모듈 3 AI 응답, 학생 프롬프트, 역할 분담 결과에 상태 라벨 추가
- 모듈 3 결과 영역 높이를 240px에서 300px로 조정
- 모듈 4 AI 행동 기록, 전송 초안·최종안, 킬스위치 기록에 상태 라벨 추가
- 각 모듈 통합 테스트에 라벨 문구 검증 추가

## 보존 및 복구

- 변경 직전 17개 파일을 `original/` 아래에 같은 상대 경로로 보관했다.
- 전체 복원이 필요할 때도 디렉터리를 통째로 덮어쓰지 않고, 필요한 원본 파일만 비교해 되돌린다.

## 검증 결과

- `npm test`: 15개 파일, 99개 테스트 통과
- `npm run lint`: 오류 0개
- `npm run build`: 성공
- 390px 모바일과 데스크톱 브라우저에서 주요 화면 확인 완료
