# 모듈 4 학생 중심 AI 행동·HITL 개편

## 목적

기존의 학부모 안내, 유료 결제, 스마트 보관함 사례를 학생의 생활과 가까운 동아리 홍보와 현장체험학습 자료 정리로 바꿨습니다. 학생이 AI 용어를 먼저 외우기보다 실제 행동을 확인·중단·복구한 뒤 개념을 이해하도록 구성했습니다.

## 활동 A · 공연 초대를 보내도 될까?

1. 학생은 동아리 공연 홍보팀의 역할을 맡습니다.
2. AI에게 연계학교 동아리 친구들에게 초대 메일과 메시지를 보내 달라고 부탁합니다.
3. AI가 공유한 준비 순서, 도구 요청, 확인 결과, 전송 요청을 페이지로 넘겨 봅니다.
4. 작년 연락처 혼입, 이전 공연 일정, 수정 전 포스터, 연락처 공개 설정을 한 장씩 확인합니다.
5. A ‘지금 모두 보내기’, B ‘멈추고 고치기’를 중심으로 선택하고, 작은 C ‘우리 동아리에 시험 전송하기’를 열어 볼 수 있습니다.
6. 고친 전송 요청을 확인한 뒤 HITL(Human-in-the-Loop)을 경험과 연결합니다.

HITL은 사람의 승인 버튼 하나를 뜻하지 않습니다. 이 활동에서는 AI가 실행 내용을 보여 주고, 사람이 근거를 확인해 승인·보류하며, 실행 뒤 결과를 다시 확인하는 구조로 설명합니다.

## 활동 B · 사라지는 견학 사진을 멈춰라

1. 박물관 견학 보고서를 위해 조별 공유 앨범의 사진과 영상을 주제별로 묶어 달라고 부탁합니다.
2. AI의 작업 기록에서 부탁하지 않은 휴지통 이동과 영상 삭제 예약을 찾습니다.
3. 비상 정지를 눌러 앞으로의 행동을 막습니다.
4. 이미 휴지통으로 옮긴 사진은 자동 복구되지 않는다는 차이를 확인합니다.
5. 원본 복원, 이동·삭제 권한 회수, 작업 기록 확인을 완료합니다.
6. 원본 읽기 전용, 복사본 정리, ‘확인 필요’ 분리, 여러 파일 변경 전 HITL, 삭제·공유 전 재확인을 설정합니다.

## UX 원칙

- 모든 주요 화면에 ‘지금 할 일’과 선택 가능한 ‘왜 할까요’를 제공합니다.
- 한 화면의 중심 행동은 하나로 제한하고, 다음 페이지 버튼을 고정된 하단 영역에 둡니다.
- 선택은 A/B를 크게 보여 주며 C는 작은 보조 버튼으로 엽니다.
- 결과 영역을 미리 확보해 선택 전후의 화면 높이 변화를 줄였습니다.
- 홈, 전체 초기화, 도움말을 학생 헤더에서 바로 사용할 수 있습니다.
- 금쪽이 스피커 연계는 활동 A 완료 화면의 한 번짜리 선택 안내로만 제공합니다.

## 교육적 회귀 조건

- 단순한 목표 전달을 삭제·발송 권한 부여로 간주하지 않습니다.
- 화면은 모델의 숨겨진 사고 과정이 아니라 공유 가능한 행동 기록을 보여 줍니다.
- HITL은 모든 위험을 없애는 장치나 책임 전가 수단으로 표현하지 않습니다.
- 비상 정지는 새 행동을 막지만 이미 일어난 결과는 복구하지 않습니다.
- 안전을 점수나 백분율로 보증하지 않습니다.
- 학생 화면과 인쇄 기록에 차시 번호를 노출하지 않습니다.
