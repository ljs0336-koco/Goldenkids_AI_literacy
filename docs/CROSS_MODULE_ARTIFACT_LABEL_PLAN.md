# 전 모듈 자료·조작·확인 상태 시각 문법 적용 계획

작성일: 2026-08-24

## 목적

학생이 화면을 보자마자 다음 세 가지를 구별하게 한다.

1. AI가 만들었거나 AI가 참고한 자료
2. 학생이 눌러 선택하는 조작 영역
3. 사람이 확인하거나 수정한 뒤의 결과

## 공통 문법

- 핵심 자료 위에만 `만든 주체/자료 종류 + 현재 상태` 라벨을 표시한다.
- AI 초안과 미확인 자료는 차분한 베이지, 확인 중인 기록은 회녹색, 사람이 확인한 결과는 민트색을 사용한다.
- A/B 선택 버튼의 기존 색과 구조는 유지한다.
- 화면마다 라벨을 반복해서 붙이지 않고, 학생이 실제로 읽고 판단할 핵심 산출물에만 사용한다.
- 라벨 글자는 모바일에서도 14px 안팎을 유지하고 좁은 화면에서는 위아래로 쌓는다.

## 적용 지점

### 모듈 1

- AI가 받은 성적표·학습 기록
- AI의 첫 진로 추천
- AI가 만든 첫 프로젝트 팀

### 모듈 2

- 기존 기사 초안의 라벨 문구를 공통 의미에 맞게 정리
- 모바일에서 기사 머리말과 확인 상태를 세로 배치

### 모듈 3

- 역할을 달리해 만든 AI 응답 후보
- 학생이 다듬어 완성한 프롬프트
- AI·자동화와 사람의 역할 분담 결과

### 모듈 4

- AI 행동 기록
- AI가 보내려는 전송 초안
- 사람이 확인한 뒤의 전송 최종안
- 이상 행동을 찾는 작업 기록

## 제외 범위

- 모든 카드를 크라프트 색으로 바꾸지 않는다.
- 상태 관리, 엔진, 로컬스토리지 형식은 변경하지 않는다.
- 인쇄 활동지와 교안 내용은 변경하지 않는다.
