# 모듈 1·2 A/B 선택 경험 개선 기록

> 변경 기준점: `7e28b18` (`feat: rebuild module 2 as verification stories`)
> 작업 영역: `src/features/fairness/**`, `src/features/verification/**`, 관련 구현 기록
> 비작업 영역: 공용 홈·라우팅·전역 스타일, 모듈 3·4, 패키지·배포 설정

## 문제

기존 페이지형 흐름은 내용을 차례로 읽는 데에는 도움이 되었지만, 선택지까지 한 장씩 넘겨 보게 하면서 다음 문제가 남았다.

- 지금 화면이 읽는 단계인지 선택하는 단계인지 구분하기 어려웠다.
- 다른 선택지를 보려면 이전·다음 버튼을 눌러야 해 선택지의 성격을 바로 비교할 수 없었다.
- 선택한 뒤 다시 다음 버튼을 찾아야 결과가 나와 반응이 늦게 느껴졌다.
- 선택 카드가 모두 비슷하게 보여 서로 반대되는 판단이라는 인상이 약했다.

## 적용한 선택 문법

```text
질문
→ A와 B를 같은 화면에서 바로 비교
→ 선택 즉시 ‘내 선택’과 결과 표시
→ 필요한 경우에만 작은 ‘다른 선택을 하고 싶다면?’ 버튼
→ 펼치면 제3안 C 표시
```

- A: 세이지색 테두리와 연한 음영
- B: 테라코타색 테두리와 연한 음영
- C: 낮은 채도의 오커색 테두리와 연한 음영
- 선택한 카드는 굵은 안쪽 테두리와 체크 표시로 구분
- 모바일에서는 A와 B를 세로로 쌓되 A/B 표시는 유지

## 적용 범위

### 모듈 1

- AI에게 되물을 질문
- 하늘이가 먼저 탐색할 꿈
- 꿈을 알아볼 다음 행동
- 프로젝트 팀을 구성할 기준
- 잘못된 기록에 대응하는 방법
- 다음 팀 구성에서 가장 먼저 지킬 약속

진로 후보와 운영 약속은 여러 개를 의무적으로 고르는 과제에서, 하나를 분명히 고르고 결과를 확인하는 활동으로 줄였다.

### 모듈 2

- 각 자료를 최종 비교에 남길지 여부
- 관찰 내용을 확인할 단서로 남길지 여부
- 첫인상에서 멈출지 출처를 더 확인할지
- 게시 전에 각 행동이 필요한지 여부
- AI 기사 문장의 근거 상태와 그 이유
- 미디어의 최종 사용 결정

미디어 최종 결정은 네 선택을 `현재 사용 가능 / 현재 사용하지 않음 / 조건을 고치거나 더 확인한 뒤 사용` 세 가지로 정리했다. 앞의 두 선택을 크게 보여 주고 조건부 결정은 제3안으로 둔다.

## 상태와 호환성

- 모듈 1 저장 키 `ai-literacy-lab:v5`, 모듈 2 저장 키 `ai-literacy-lab-verification:v1`은 유지한다.
- 모듈 1의 진로와 운영 약속은 각각 하나만 저장하도록 정제한다.
- 모듈 2의 이전 `more_info` 결정은 새 선택 목록에 없으므로 저장 상태를 읽을 때 제거된다. 해당 사건은 다시 판단하면 된다.
- 모듈 3·4 저장 상태와 파일에는 접근하지 않는다.

## 검토 포인트

- A와 B가 한눈에 서로 다른 선택으로 보이는가?
- 제3안 버튼이 너무 눈에 띄어 다시 세 선택처럼 보이지 않는가?
- 선택 직후 나타나는 결과가 다음 행동을 충분히 설명하는가?
- 모바일에서도 A/B의 순서와 색 의미가 유지되는가?
- 선택을 줄였지만 학생이 생각해야 할 핵심 차이는 남아 있는가?
