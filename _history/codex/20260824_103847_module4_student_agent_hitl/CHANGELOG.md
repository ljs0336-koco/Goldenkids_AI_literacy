# 변경 기록

## 목적

모듈 4를 성인·교사 중심 프로토타입에서 학생 공동체 안의 실제 행동을 다루는 자기주도 체험으로 개편했습니다. AI가 메시지를 보내거나 파일을 바꿀 때의 사람 확인, 비상 정지, 복구, HITL을 학생 언어로 연결했습니다.

## 주요 변경

- 모듈명: AI 에이전트 통제실 → AI가 대신 움직인다면?
- 활동 A: 학예회·학부모 메일·결제·보관함 사례 → 학생 동아리 공연 초대 전송
- 활동 B: 간식 중복 결제 → 박물관 견학 사진·영상 분류 사고
- 작업 기록을 한 장씩 넘기는 페이지형 흐름으로 재구성
- A/B 중심 선택과 작은 C 선택지, 선택 즉시 결과 영역 추가
- 모든 핵심 화면에 ‘지금 할 일’과 ‘왜 할까요’ 안내 추가
- 학생 도움말, 홈, 전체 초기화 유지
- 교사 도구와 발표 모드 제거
- HITL(Human-in-the-Loop)을 활동 뒤 개념화
- 비상 정지와 이미 일어난 결과의 복구를 별도 페이지로 분리
- 안전 준비도 점수와 백분율 제거
- 저장 키를 ai-literacy-lab-agent:v3로 갱신
- 금쪽이 스피커 연계는 활동 A 완료 화면의 선택 안내 한 번으로 제한

## 알려진 제한

- 모든 메일·메시지·파일 작업은 실제 서비스와 연결되지 않은 수업용 가상 시뮬레이션입니다.
- 공연 일정과 연락처 수, 사진 수는 활동 안에서만 쓰는 가상 정보입니다.
- 브라우저 저장소 v2 기록은 v3로 자동 변환하지 않고 새 활동으로 시작합니다. 전체 초기화 시 v1·v2·v3를 모두 정리합니다.
