# Antigravity 인계서

## 변경 목적

모듈 1에 상단 `이 화면에서는` 안내와 하단 `지금 해볼 일` 안내가 동시에 보여 학생의 시선이 분산됐다. 상단 안내를 렌더링하지 않고 장면별 행동을 알려 주는 하단 안내만 유지했다.

## 공용 진행 표시

- `src/components/ProgressStepper.jsx`에서 단계 번호를 원형 마일스톤으로 분리했다.
- 완료 단계는 체크 표시, 현재 단계는 진한 원형과 밑줄, 예정 단계는 옅은 원형으로 보인다.
- `src/styles/global.css`의 공용 스타일이므로 모듈 1·2·3·4에 모두 적용된다.
- 데스크톱은 한 줄 로드맵, 680px 이하는 2×2 로드맵이다.

## 주의할 점

- 모듈 1의 `StepPurposeBar`는 더 이상 `FairnessLabPage`에서 렌더링하지 않는다.
- 하단 `LearningGuideToast`는 장면마다 바뀌는 클릭 안내이므로 제거하지 않는다.
- 각 모듈의 단계 배열에 들어 있는 `①`, `②` 등의 번호는 공용 컴포넌트가 마일스톤으로 분리해 사용한다.
- 로드맵을 모듈별 CSS로 다시 덮어쓰지 않는다.
