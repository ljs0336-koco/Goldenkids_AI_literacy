# 모듈 1·2 클릭 안내·고정 무대 개선 기록

> 작업일: 2026-08-21
>
> 변경 기준점: `968c44d` (`feat: clarify module choices with A B paths`)
>
> 작업 범위: 공통 헤더·안내 컴포넌트, 모듈 1 `fairness`, 모듈 2 `verification`
>
> 비작업 범위: 모듈 3 `role`, 모듈 4 `agent`, 라우트·홈 콘텐츠, 패키지 설정

## 해결하려던 문제

- 학생이 화면을 넘긴 뒤 어디를 보고 무엇을 눌러야 하는지 바로 알기 어려웠다.
- 전체 활동 기록을 지우고 홈으로 돌아가는 명시적인 동작이 없었다.
- 미디어 게시 활동의 합성 이미지가 카드 영역에 맞춰 강제로 늘어나 인물이 퍼져 보였다.
- A/B 선택, 제3안 열기, AI 응답 표시 때 새 콘텐츠가 생기면서 카드 높이와 아래 버튼 위치가 계속 움직였다.

## 적용 내용

### 1. 단계별 ‘지금 해볼 일’ 안내

- 모듈 활동을 시작하거나 큰 단계가 바뀌면 화면 아래에 7초 동안 안내가 뜬다.
- 안내는 교육 목표를 반복하지 않고, `가운데 무엇을 보고 → 어느 버튼을 누를지`만 말한다.
- 한 단계 안에서 `다음 장면·다음 자료`로 넘겨도 새 안내가 뜬다.
- A/B를 고르거나 제3안을 열면 결과가 나타난 위치와 다음 행동을 알려 준다.
- 안내는 `position: fixed`로 본문 위에 떠서 콘텐츠 배치를 밀지 않으며, 닫기 버튼과 `aria-live`를 제공한다.

### 2. 공통 홈·전체 초기화

- 공통 헤더에 `홈`, `전체 초기화` 버튼을 항상 표시한다.
- 전체 초기화는 확인 창을 거친 뒤 모듈 1~4의 앱 전용 저장 키만 삭제하고 `#/`로 이동한다.
- 브라우저의 다른 서비스나 설정에 해당하는 로컬스토리지 값은 지우지 않는다.
- 기존 교사 도구 안의 모듈별 초기화는 `현재 활동만 다시`로 구분했다.

### 3. 미디어 이미지 비율 복구

- 2×2 합성 이미지에 적용하던 `width: 200%; height: 200%; object-fit: fill`을 제거했다.
- 원본 가로세로 비율을 유지한 채 각 사분면을 위치로 잘라 보여 준다.
- 활동 선택 카드의 두 이미지 영역 높이를 맞춰 카드 자체도 안정적으로 보이게 했다.

### 4. 흔들리지 않는 콘텐츠 무대

- 모듈 1 활동 카드는 데스크톱 최소 760px, 모바일 최소 720px의 기본 무대를 가진다.
- 모듈 2 활동 카드는 데스크톱 최소 800px, 모바일 최소 740px의 기본 무대를 가진다.
- 선택 전에도 결과 자리, 제3안 자리, AI 답변 자리, 기준 설명 자리, 이의제기 결과 자리를 미리 확보한다.
- 빈 자리는 다음에 무엇이 나타날지 짧게 알려 주므로 의미 없는 공백으로 보이지 않는다.
- 자료 봉투와 문장 판정의 후속 이유 영역도 높이를 확보해 열기·선택 후 아래 탐색 버튼이 갑자기 밀리지 않게 했다.
- 고정 `height`가 아니라 `min-height`를 사용해 작은 화면이나 긴 문장에서는 잘리지 않고 아래로 확장된다.

- 모듈 1·2 및 공통 컴포넌트: `8 files / 64 tests` 통과
- 전체 앱: `15 files / 97 tests` 통과
- 정적 검사: `npm run lint` 오류·경고 없음
- 배포 빌드: `npm run build` 성공, 125개 모듈 변환
- `git diff --check`: 공백 오류 없음

앱 내 브라우저 자동 검토는 브라우저 플러그인의 로컬 신뢰 경로 오류로 연결되지 않았다. 별도 브라우저 자동화로 우회하지 않고 DOM 통합 테스트, CSS 비율 계산, 프로덕션 빌드로 검증했다. 실제 브라우저에서는 아래 항목을 우선 확인한다.

1. `/verification` 첫 화면 오른쪽 인물이 가로로 퍼지지 않는가?
2. 활동을 시작하면 아래 안내가 본문을 밀지 않고 잠깐 뜨는가?
3. A/B 선택 전후와 제3안 열기 전후에 아래 버튼 위치가 크게 움직이지 않는가?
4. 작은 화면에서 긴 콘텐츠가 잘리지 않고 자연스럽게 스크롤되는가?
5. 전체 초기화 확인 후 네 모듈의 완료 표시가 모두 초기 상태가 되는가?

## Antigravity 인계 메모

- `src/features/role/**`, `src/features/agent/**` 파일은 수정하지 않았다.
- 공용 변경 파일은 `src/components/AppHeader.jsx`, `src/components/LearningGuideToast.jsx`, `src/styles/global.css`, `src/utils/learningGuide.js`, `src/utils/learningProgress.js`이다.
- 공용 헤더 변경으로 모듈 3·4에도 홈·전체 초기화 버튼이 자동 노출된다.
- 모듈 3·4에서 단계별 팝업까지 사용하려면 각 페이지에 `LearningGuideToast`를 마운트하고, 내부 페이지 넘김에서 `announceLearningGuide()`를 호출하면 된다. 이번 작업에서는 소유 영역 격리를 위해 해당 파일을 수정하지 않았다.
- GitHub 반영 시 이 커밋을 먼저 가져온 뒤 공용 파일을 이전 버전으로 덮어쓰지 않는다. `dist/`는 이번 소스로 다시 빌드되어 있다.
