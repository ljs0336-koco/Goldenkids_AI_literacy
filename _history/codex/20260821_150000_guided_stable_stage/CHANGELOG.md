# 클릭 안내·고정 무대 변경 이력

## 공용

- 단계별 비차단 안내 컴포넌트와 안내 이벤트 추가
- 헤더에 홈·전체 초기화 추가
- 앱 전용 저장 키만 제거하는 초기화 유틸리티 추가
- 초기화 확인 대화상자와 안내 토스트 스타일 추가

- 단계별 클릭 안내 문장 연결

- 선택 결과, AI 응답, 기준 설명, 이의제기 결과 자리 고정
- 활동 카드의 최소 높이 안정화

## 모듈 2

- 단계별 클릭 안내 문장 연결
- 내부 자료 이동·A/B 선택·제3안 열기 안내 연결
- 미디어 합성 이미지 강제 늘림 제거
- 자료 봉투, 선택 결과, 후속 판정 이유 자리 고정
