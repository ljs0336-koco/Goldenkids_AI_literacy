## 1. 학생용 명칭

- 모듈: `AI의 선택, 그대로 믿어도 될까?`
- 활동 A: `AI가 하늘이의 꿈을 골라 줘도 될까?`
- 활동 B: `프로젝트 팀을 AI에게 맡겨도 될까?`

## 2. 진로 활동 흐름

```text
하늘이 소개와 고민
→ AI가 실제로 받은 자료
→ AI의 첫 직업 제안
→ AI에게 이유·빠진 정보 질문
→ 성적표 밖의 하늘이 이야기 네 가지
→ 더 알아볼 꿈 두 가지 선택
→ 실제 탐색 행동 한 가지 선택
→ 처음과 달라진 탐색 계획 확인
```

### 주요 변경

- 점수와 기록보다 하늘이의 소개와 고민을 먼저 보여 준다.
- `AI 추천 점수`, `적합도`, `단서 점수`는 학생 화면에 노출하지 않는다.
- 직업 하나를 최종 답으로 정하지 않고 네 가지 가능성 중 두 가지를 더 알아보게 한다.
- 반복 확인 체크리스트를 없애고 인터뷰·정보 탐색·직접 경험 같은 다음 행동으로 마친다.
- 금쪽이 스피커 안내는 AI에게 되묻는 장면의 작은 선택형 메모로만 둔다.

## 3. 프로젝트 팀 활동 흐름

```text
학교 프로젝트 목표와 필요한 역할
→ AI가 빠르게 만든 첫 팀
→ 프로젝트에서 중요하게 볼 기준 선택
→ 기준 변경 전후 명단 비교
→ 달라진 기회와 역할 확인
→ 한결이의 잘못된 기록 발견
→ 대응 선택
→ 기록·팀·절차 결과를 페이지별로 확인
→ 다음에 지킬 약속 두 가지 선택
```

### 주요 변경

- 지원자 8명을 의무적으로 모두 읽는 단계는 제거했다.
- 전체 후보 기록은 필요한 학생만 열어 보는 보조 자료로 남겼다.
- 기준 가중치 백분율을 학생 화면에서 숨기고, 각 기준이 중요하게 보는 가치와 놓칠 수 있는 점을 보여 준다.
- 결과 화면에서 내부 계산 점수를 제거하고 명단 변화, 기회 변화, 역할 구성을 중심으로 설명한다.
- 기록 정정 결과를 한 화면에 쌓지 않고 `기록 → 팀 → 재검토 절차`로 나눈다.
- 다섯 원칙 중 세 개를 고르는 과제를 세 가지 핵심 약속 중 두 가지를 고르는 활동으로 줄였다.

## 4. 저장 상태와 호환성

- 기존 로컬스토리지 키 `ai-literacy-lab:v5`는 유지한다.
- `growthCareerChoices`를 추가하고 허용된 진로 ID 두 개만 저장한다.
- 이전 버전에 저장된 운영 원칙은 새 원칙 목록과 맞지 않으면 제거한다.
- 이의제기 선택은 `1`, `2`, `3`만 허용한다.
- 기존에 진행 중이던 상태가 손상되어도 화이트리스트 검증 후 안전한 값으로 복구한다.

## 6. Antigravity 인계 사항

- 모듈 1 담당 영역 `src/features/fairness/**`는 이 구현 이후 임의 수정하지 않는다.
- 모듈 3·4에서 페이지형 경험을 적용할 때 모듈 1의 이야기 형식을 그대로 복제하지 않는다.

- 공용 페이지 컴포넌트로 승격할 변경이 필요하면 먼저 변경안을 공유하고 통합 담당자가 적용한다.
