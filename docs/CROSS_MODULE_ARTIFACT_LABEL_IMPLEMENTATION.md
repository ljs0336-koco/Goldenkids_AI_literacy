## 구현 결과

학생이 핵심 콘텐츠를 읽을 때 `누가 만든 것인지`와 `지금 어떤 상태인지`를 바로 알 수 있도록 공통 라벨을 도입했다.

| 구분 | 표현 예시 | 의미 |
| --- | --- | --- |
| AI 또는 입력 자료 | `AI 추천 초안 · 사람 확인 전` | AI가 제안했으며 그대로 확정된 답이 아님 |
| 확인 중 기록 | `AI 행동 기록 · 사람 승인 필요` | 학생이 내용을 읽고 개입해야 함 |
| 사람 확인 결과 | `사람 확인 반영 · 전송 전 최종안` | 사람의 판단이 반영된 결과임 |

공통 컴포넌트는 `src/components/ArtifactStatusLabel.jsx`, 공통 스타일은 `src/styles/global.css`에 두었다. 모듈 전용 화면에서는 문맥에 맞는 문구와 상태 색만 전달한다.

## 모듈별 적용

### 모듈 1

- 성적표·학습 기록: `AI가 받은 자료`
- 첫 진로 추천: `사람 확인 전`
- 첫 프로젝트 팀: `기준 확인 전`

### 모듈 2

- 기사 초안을 `AI 기사 초안`, 상태를 `사람 확인 전`으로 간결하게 정리했다.
- 620px 이하에서 기사 머리말과 확인 상태를 세로로 배치하고 글자 크기를 14px로 유지했다.

### 모듈 3

- AI 응답 후보: `내가 고를 차례`
- 학생이 다듬은 부탁: `사용 전 확인`
- 역할 분담 결과: `사람 최종 결정`
- 라벨 추가 뒤 결과 내용이 내부 스크롤에 가려지지 않도록 결과 영역 높이를 300px로 조정했다.

### 모듈 4

- AI 행동 기록은 단계에 따라 현재 상태를 함께 표시한다.
- 전송 초안은 `사람 확인 전`, 수정 결과는 `전송 전 최종안`으로 구분한다.
- 킬스위치 기록에는 `부탁 범위 안`, `주의 필요`, `범위 이탈` 상태를 표시한다.
