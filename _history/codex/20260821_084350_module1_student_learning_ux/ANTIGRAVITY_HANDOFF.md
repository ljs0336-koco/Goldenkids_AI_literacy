# Antigravity 인계 — 모듈 1 학생 자율 탐구 UX

## 적용 범위

- Codex 전담 변경: `src/features/fairness/**`
- 공용 변경: `src/components/AppHeader.jsx`
- 공용 헤더 변경은 새 선택 옵션 `studentMode`, `onHelp`뿐이며 기본값은 기존 모드다.
- 모듈 2·3·4의 기능 파일과 라우트는 수정하지 않았다.

## 업로드 전에 알아둘 점

1. 모듈 1은 상단 `교사 도구`, `발표 화면`, `활동지`를 의도적으로 숨긴다.
2. 다른 모듈은 `studentMode`를 넘기지 않으므로 기존 헤더가 유지된다.
3. 금쪽이 스피커 연결은 음성 인식이나 하드웨어 API가 아니다. 학생이 실제 챗봇과 대화했는지 또는 준비된 응답을 쓸지 선택하는 교육적 연결 장치다.
4. 준비된 AI 응답에는 학습용 시뮬레이션 표시가 있다. 실시간 생성형 AI처럼 표현하면 안 된다.
5. 스토리지 키는 계속 `ai-literacy-lab:v5`이며 새 필드는 엄격한 화이트리스트 검증을 거친다.

## 충돌 방지

- 업로드/병합 전 `src/components/AppHeader.jsx` 충돌 여부를 먼저 확인한다.
- 모듈 1 파일을 Antigravity 쪽 이전 사본으로 덮어쓰지 않는다.
- `dist/**`는 최종 통합 담당자가 한 번만 새로 빌드한다.
- 이 커밋 이후 다른 에이전트 변경이 있다면 `git pull` 또는 병합 후 전체 테스트와 빌드를 다시 실행한다.

- 대표팀: 학습 브리프 → 금쪽이 대화 방법 선택 → 지원자 8명 → 기준 선택 → AI 설명 요구 → 이의제기 3가지 결과 → 원칙 → 탐구 기록

## 알려진 검증 제한

Codex 환경에서 자동 브라우저 연결이 trusted RPC 경로 오류로 실패했다. 단위·통합 테스트, 린트, 빌드와는 무관하다. 배포 전에 실제 브라우저에서 위 수동 체크를 한 번 수행해 달라.
