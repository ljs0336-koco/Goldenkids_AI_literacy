# 모듈 2 클릭 반응형 활동 A 시범 구현

작성일: 2026-08-24  
범위: 모듈 2 활동 A `학교신문 AI 초안 검증`  
상태: 구현·자동 검증·브라우저 검증 완료

## 구현 결과

활동 A를 `선택 → 변화 → 확인 → 완료` 문법으로 개편했다.

- `AI 초안`, `사람 확인 중`, `함께 완성`, `사람 확인 완료`가 같은 위치에서 바뀐다.
- 첫 화면에 `AI 금쪽이 · 기사 초안 작성 도움`을 명확히 표시한다.
- 실제 챗봇이 연결되지 않은 현재 상태를 `가상 체험`으로 표시한다.
- 자료 봉투, 문장 카드, 비교 자료가 바뀔 때 짧은 장면 전환을 사용한다.
- A/B 선택 결과는 하단 팝업이 아니라 활동 카드 내부의 고정 결과 영역에 나타난다.
- 의미 있는 완료 순간에만 역할·완료 라벨이 짧게 활성화된다.
- 모션 감소 설정에서는 이동과 강조 애니메이션을 제거한다.

## 안내 체계

모듈 2에서는 상단 `지금 할 일`을 유일한 지속 안내로 유지한다.

- 페이지 진입 시 자동으로 나타나던 하단 `지금 해볼 일` 팝업을 제거했다.
- 페이지 넘김과 A/B 선택 직후 같은 안내를 반복하던 이벤트 호출을 제거했다.
- 선택 결과와 다음 행동은 현재 카드 안에서 바로 확인한다.

이 변경은 모듈 2 공통 페이지 전환·선택 컴포넌트에 적용되므로 활동 B에서도 중복 팝업만 제거된다. 활동 B의 역할 라벨과 장면 전환은 아직 적용하지 않았다.

## 챗봇 연결 표시

현재 학생 화면에는 다음 내용을 표시한다.

```text
누가 만들었나요? · AI 초안
AI 금쪽이 · 기사 초안 작성 도움

체험 방식 · 가상 체험
실제 챗봇 연결 전이라, 미리 준비된 AI 답변으로 연습해요.
```

실제 연결할 챗봇 이름과 실행 링크는 아직 정의하지 않았다. 이름을 임의로 붙이거나 연결된 것처럼 표현하지 않는다.

## 화면 안정성

- 기존의 자료 봉투 610px 예약 영역을 유지했다.
- 브라우저 측정에서 닫힌 봉투, 열린 봉투, 선택 결과 표시 후 높이가 모두 610px이었다.
- A/B 결과 영역은 선택 전에도 최소 높이를 유지한다.
- 모바일에서는 라벨을 한 열로 배치하고 고정 높이를 강제하지 않는다.

## 브라우저 검증

### 데스크톱

- 활동 선택 → AI 초안 → 문장 선택 → 자료 3개 판단 → 자료 비교 → 판정 → 문장 수정 흐름을 직접 실행했다.
- 판정 후 `AI 초안 / 사람 확인 중`이 `함께 완성 / 사람 확인 완료`로 바뀌는 것을 확인했다.
- 하단 중복 안내가 나타나지 않았다.
- 신규 경고·오류 로그가 없었다.

### 모바일

- 390×844 화면에서 확인했다.
- 작업 라벨이 한 열로 배치됐다.
- 문장 수정 전후 비교가 세로로 전환됐다.
- 가로 넘침이 없었다.

## 사용자 검토 지점

1. 역할 라벨 두 장이 눈에 잘 들어오는가.
2. `가상 체험` 설명이 실제 챗봇 연결 여부를 충분히 알려 주는가.
3. 자료 봉투와 문장 카드 전환이 자연스러운가.
4. 완료 라벨 효과가 과하거나 약하지 않은가.
5. 활동 A의 문법을 활동 B와 다른 모듈에 확장할 가치가 있는가.

사용자 검토 전에는 활동 B와 모듈 1·3·4에 새 상호작용 체계를 적용하지 않는다.
