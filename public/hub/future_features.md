# [미구현 기능 명세서] 향후 고도화 및 연동 계획 (Future Features)

- **작성자**: 마루 (파이프라인 및 프로토타이핑 전담)
- **수신**: 미르 (기획·디자인), 모루 (품질 감사), 강사님
- **작성일시**: 2026-09-29
- **현재 단계**: 프로토타입 v0.1 (화면·데이터 구조·페이지 이동 검증 완료)

본 문서는 현재 프로토타입 단계에서는 과도한 기술적 복잡성을 배제하기 위해 의도적으로 구현을 유보하고, 향후 모루의 교육적 검토 및 강사님의 현장 운영 계획에 따라 단계별로 추가할 기능들을 명시합니다.

---

## 1. 백엔드 데이터베이스 및 영속성 (Backend DB)
- **현재 구현 상태**: 
  - 8개 팀 기획 데이터 및 기본 피드는 클라이언트 자바스크립트 객체(`TEAMS_DATA`, `INITIAL_NOTES_DATA`)로 인메모리 관리.
  - 사용자가 작성한 새 메모와 교사 피드백은 브라우저의 `LocalStorage`에 저장되어 새로고침 시에도 유지됨.
- **향후 연동 계획**:
  - **Supabase 또는 Firebase Firestore** 연결을 통해 다중 사용자 간 실시간 CRUD 구현.
  - 학생 제출물(과제, 일지)의 클라우드 영구 저장소 구축.

---

## 2. 사용자 인증 및 역할 분담 (Authentication & Roles)
- **현재 구현 상태**:
  - 별도 로그인 없이 8개 팀의 현황, 커리큘럼, 사이드 앱, 메모장을 자유롭게 열람·시연할 수 있는 오픈 샌드박스 형태.
- **향후 연동 계획**:
  - **교사(Teacher) vs 학생(Student) 권한 분리**:
    - 교사용: 8개 팀 전체 대시보드 열람, 피드백 작성 권한, 공지사항 핀 고정.
    - 학생용: 자기 팀 과제 편집, 사이드 앱 조작, 팀 토의 메모 작성.
  - 구글 교육용 계정(Google Workspace for Education) OAuth 2.0 연동.

---

## 3. 실제 AI API 실시간 호출 (Live LLM API Integration)
- **현재 구현 상태**:
  - 사이드 앱 플레이어는 소크라틱 발문 시뮬레이터의 프레임과 UI 인터랙션(오개념 해소 신뢰도, 평가 점수, 문답 턴)을 모의(Mock)로 제공.
  - 플레이어 내부에 "강사님이 Google Build / AI Studio 등으로 구현할 맞춤형 시뮬레이터를 드롭인할 수 있는 전용 슬롯" 안내 배치.
- **향후 연동 계획**:
  - **Google AI Studio (Gemini 1.5 Pro / Flash API)**를 직접 바인딩하여, 학생이 입력창에 질문을 작성하면 실제 소크라테스식 반박 발문을 실시간 스트리밍으로 생성.
  - API 키 노출 방지를 위해 경량 Vercel Serverless Function 또는 Cloudflare Workers 프록시 적용.

---

## 4. 실제 파일 업로드 및 클라우드 동기화 (File Upload & Cloud Storage)
- **현재 구현 상태**:
  - 외부 과제 허브(구글 드라이브, 패들렛, 노션, 스프레드시트)는 실제 업무 도구 링크 및 열기 인터랙션(토스트 알림)으로 동작.
  - 메모 작성 바의 링크 및 사진 첨부 버튼은 UI 프로토타입 상태로 유지.
- **향후 연동 계획**:
  - 구글 드라이브 API 또는 AWS S3 연동을 통한 실제 HWPX/DOCX/PPTX 파일 업로드 및 버전 관리(v1.0, v1.1 등).

---

## 5. 실시간 다자간 웹소켓 동기화 (Real-Time WebSocket Sync)
- **현재 구현 상태**:
  - 공유 메모장은 개별 브라우저 세션 내에서만 즉시 추가/조회됨.
- **향후 연동 계획**:
  - 교사가 프로젝터 화면에 대시보드를 띄워둔 상태에서, 학생들이 스마트폰으로 메모를 올리면 새로고침 없이 프로젝터 화면에 실시간 피드가 갱신되는 WebSocket/Pusher 채널 연동.
