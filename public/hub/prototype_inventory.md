## 2. `_3/code.html` 상세 분석 보고

- **검증 방법**: `_1/code.html`과 `_3/code.html`의 텍스트 및 라인 단위 `difflib` 전수 대조 실행.
- **결과**: 총 45,464자 중 45,388자가 완전 일치하며, 차이점은 라인 218에 삽입된 다음 5줄의 CSS 코드뿐임.
  ```html
  <style>
    body {
      min-height: max(884px, 100dvh);
    }
  </style>
  ```
- **판정 및 처리**: `_3`은 모바일 브라우저의 주소창 유동성에 대응하기 위해 `100dvh`를 테스트한 **`_1`의 기술적 변형본**임. 별도의 화면으로 분리하지 않고, 해당 CSS 뷰포트 보정 속성을 프로토타입 공통 셸에 흡수 적용함.

## 3. 라우팅 및 화면 전환 구조 설계

브라우저 히스토리(`pushState`/`hashchange`)와 완전 호환되는 경량 클라이언트 라우터 구현:

```text
[하단 4대 내비게이션 바]
  ├── [과제/프로젝트] ─── #projects   ───> 학급 대시보드 (_1)
  │                      └─ #team/:id  ───> 팀별 상세 뷰 (_2) (카드 클릭 또는 칩 선택)
  ├── [커리큘럼]     ─── #curriculum ───> 8차시 커리큘럼 뷰어 (8_e_book)
  ├── [사이드 앱]     ─── #apps       ───> 사이드 앱 플레이어 & 아카이브 (_4)
  └── [공유 메모장]   ─── #notes      ───> Notes 협업 피드 (_5)
```

- 새로고침 시에도 현재 해시(#) 경로가 유지됨.
- 브라우저 뒤로가기/앞으로가기 완벽 지원.
- 팀 상세(#team/01)에서 대시보드로 돌아가는 상단 뒤로가기 버튼 완비.
